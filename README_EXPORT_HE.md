# נס מולטימדיה: ייצוא קוד הפרויקט

הארכיון כולל את קוד ממשק המשתמש, קוד פעולות השרת הקיים, סכימת בסיס הנתונים ועדכוניה, קובצי ניהול התלויות, נכסי הפרויקט הציבוריים והתיעוד הקיים שנכללו בפרויקט השמור.

שירותי ההתחברות, בסיס הנתונים, אחסון הקבצים ותשתית ההרצה מנוהלים בנפרד על ידי הפלטפורמה. הקוד המתחבר אליהם כלול; השירותים עצמם ותוכנם אינם כלולים.

הייצוא אינו גיבוי נתונים ואינו התקנה עצמאית מוכנה להפעלה. לא נכללו נתוני לקוחות ואירועים חיים, קובצי סביבה, פרטי גישה, ספריות תלויות מותקנות או תוצרי בנייה. נתוני אתחול נפרדים לא נכללו. להפעלה נדרש להתאים את השירותים המנוהלים ולהתקין את התלויות לפי קובצי הפרויקט.

לא בוצעו שינוי באתר, בנייה מחדש או פרסום במסגרת הייצוא.
